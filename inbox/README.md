INBOX — drop raw photos here
============================
Dump your raw product photos here (HEIC or JPG), unsorted. A few shots per item
(e.g. front, label, back). The agent groups them per product automatically.

Flow:  inbox/  ->  [agent: analyse + create draft]  ->  posted/  (and LISTINGS.md)
Unsure items go to ../review/ for you to check.
